# Gals-RNG 0.2.9 — Рецензия кода и дизайна

*Подготовлено на ветке `arena/01a03f26-gals-rng` (основано на коммите `7b10959`, тег 0.2.9). `main` не тронут.*

## 1. Как устроена игра (картина целиком)

**Стек:** чистый vanilla JS без сборщика, 12 JS-файлов (~15 000 строк), Bootstrap 5 + GSAP + PIXI (CDN), localStorage для сейвов.

| Файл | Роль |
|---|---|
| `js/cards.js` | 144 редкости (данные карт), мутации, магазин, «донные» редкости |
| `js/game.js` | Ядро: роллы, удача, престиж, экипировка, бусты, крафт, ачивки |
| `js/ui.js` | Весь UI: рендер вкладок, анимация ролла, авторолл, AFK-догон |
| `js/visualEffects.js` | ~20 визуальных эффектов (GSAP/PIXI) + музыка эффектов |
| `js/events.js` | Датовые ивенты (8 шт., все уже закончились) |
| `js/achievements.js` | 20 достижений + 4 коллекции |
| `js/crafting.js` | 20 материалов, дроп с карт, 7 рецептов |
| `js/saveManager.js` | localStorage, троттлинг, экспорт/импорт |
| `js/localization.js` + `locales/*` | RU/EN (778 = 778 ключей, полностью синхронизированы) |
| `js/debug.js` | Консольная дебаг-панель (в UI нет кнопки — открывается через консоль) |

**Алгоритм ролла** (`game.js → performRoll`): проходим редкости от самой редкой к самой частой; у каждой свой независимый чек `p = (o·L)/(1+o·L)`, где `o = P/(1−P)`, `L` — итоговая удача. Кто сработал первым — тот выпал; не сработал никто — `garbage`. Удача множит «оддсы» линейно, поэтому сильно помогает именно редким картам (как и задумано).

**Системы:** удача (база + ядро + престиж + экипировка + стаки несчастья + мотивация + бусты + катализатор + дубли чёрной дыры), Lucky Roll (×2 каждые 11 роллов), мутации (Негатив/Золотая/Пустотная), механические эффекты (1 активный «слот» на карте), пассивки (берутся от самой редкой карты семьи), материалы → крафт → темы/экипировка/карта, престиж (бонус за уникальные карты, сброс прогресса кроме коллекции), 9 тем, safe-режим 18+, саппортеры (4-й слот + алмазная карта через Google-таблицу), экспорт/импорт сейва.

## 2. Что сделано хорошо

1. **Данные отделены от логики** — новая карта = один объект в `cards.js` + 2 строки локализации. Масштабируется безболезненно.
2. **Оптимизации 0.2.9 реальные**: `RARITY_MAP` (O(1) поиск), инкрементальный рендер инвентаря (Map существующих узлов, перенос вместо пересоздания), троттлинг сейвов 700 мс + flush при закрытии вкладки.
3. **Прозрачность удачи** — «Состав удачи» в статистике (`getLuckBreakdown`) — редкая и очень полезная вещь для gacha-игр.
4. **Локализация на равных**: RU/EN — 778 ключей с каждой стороны, ни одного рассинхрона.
5. **Ивенты-лимитки → коллекции → премиум-темы** — красивый контентный цикл (шоколадка/хэллоуин/крипипаста).
6. **Мутации дают стратегию**: Золотая (×3 валюта) vs Пустотная (0 валюты, но материалы ×3 гарантированно) — игрок выбирает под цель.
7. **Нить Судьбы** — приятный престиж-QoL, снимает боль сброса экипировки.
8. **Safe-версии карт** и переключатель «особого контента» — грамотная модерация 18+.
9. **AFK-догон в чанках** через requestAnimationFrame — идея правильная (см. §3.2 по реализации).
10. Престиж награждает **ширину коллекции** (per-card бонус) — правильно мотивирует собирать всё.

### 3.2 Производительность и размер

- **Репозиторий 717 МБ.** Картинки карт — PNG 1024×1360 по 1,3–5,4 МБ каждая (`cardDoctor.png` 5,4 МБ, `cardMetal.png` 5,0 МБ, `cardMoon.png` 4,9 МБ). Инвентарь использует полноразмерные арты как есть: при полной коллекции браузер тянет ~300+ МБ картинок.
  → **WebP + миниатюры** для грида (~300–400px), полный арт только в модалке. Репозиторий ужатится в 5–7 раз, инвентарь станет мгновенным на мобилках.
- Аудио: 83 МБ. `timestop-sfx.mp3` 23 МБ и `motivation-sfx.mp3` 19 МБ — перегруз для SFX; сжатие до 1–2 МБ не потеряет слышимость.
- Нет PWA (manifest/favicon) — игра идеально подходит для «поставил на телефон и фармишь».
- GSAP-плагины на CDN: Flip/MotionPath/ScrambleText/SplitText/CustomBounce/CustomWiggle — большинство не используются, можно удрать лишние (меньше сетевых запросов).

### 3.3 Экономика и баланс (цифры из симуляции)

Симулировал реальный алгоритм ролла (итерация от редкого, чек `oL/(1+oL)`):

| Удача | % мусора | % классики (common–legendary) | % реже легендарки |
|---|---|---|---|
| 1.0 | **52,5%** | 36,2% | 4,0% |
| 2.0 | 30,1% | 50,3% | 7,8% |
| 5.0 | 8,0% | 57,3% | 18,2% |
| 10.0 | 1,5% | 51,3% | 32,5% |

**Главный узел — первый престиж (1 000 000 💎):**

| Режим | Время до первого ребёрна |
|---|---|
| 1 ролл / 2 сек (база) | **~76 часов** |
| + bуст удачи до 2.0 | ~43 часа |
| multi x5 + fast roll (4 ролла/сек) | ~11 часов |

Для AFK-игры «долго» — приемлемо, но 76 часов без мульти-ролла (а он стоит 7 500 💎, т.е. сам покупается только после длинного фарма) — это **стена удержания** на первых днях. Докупить удачу бустами тоже дорого: бусты стоят дороже, чем текущий доход игрока позволяет брать часто.

Остальные наблюдения:

- Доход ранней игры — ~3–4 💎/ролл (дубли классики), мусор даёт 0 валюты (но 25% шанс лома — это хорошо, крафт уже ранний).
- `gal` (1/1e9): даже с удачей 10 — 100 млн роллов (~30 ч на 4 ролла/сек). Это «граль», ок по духу, но у игры **нет никакого pity-механизма** кроме Lucky Roll ×2.
- Кривая дублей поздних карт (1,25–30 млн за дубль при 1/12 млн+) — нормальный скачок после престижа.
- `bottomFeederRarities` = ровно 12 карт (common…coal) — совпадает с описанием «Донной Длани». ✔
- Мутации: Золотая 0,6% → ×3 к дублю — адекватный риск-ревард; кэп 25% на каждую мутацию с линзой (+50%) — здоровый баланс.
- Prestige: таблица 11 уровней, per-card 0,010→0,040 — рост не обваливает кривую. ✔

## 5. «А переделывать целиком?»

**Нет, не надо.** Архитектура (данные отдельно, IIFE-модули, O(1)-мапы, инкрементальный рендер) выдержана и масштабируется — 144 карты и 9 тем уже на ней живут. Полный ребилд (фреймворк/сборщик/типы) дал бы мало геймплейной ценности и большой риск регрессий на 700 МБ ассетов.

Ценность сейчас — в **этапах 1–3**: это ~80% «ощущения улучшения» за 20% объёма работы. Единственное, что я бы сделал структурно — вынес баланс-симулятор (такой, что гонял для этого обзора) в `tools/balance-sim.js`, чтобы перед каждым изданием проверять распределения и кривую дохода численно, а не «на глаз».
